# 개발 계획 (DAY 1~5 수직 슬라이스)

각 단계가 끝날 때마다 플레이 가능한 상태로 배포한다. 순서는 GAME_DESIGN.md §30과 같다.

| 단계 | 내용 | 상태 |
|---|---|---|
| M0 기반 | 프로젝트, 테스트·빌드, 배포 설정, 기획서 저장 | 완료 (배포 저장소 대기) |
| M1 강화 | 무기·강화·저장, 확률표 + 시뮬레이션, 낮 대장간, 원클릭 망치 연출, 첫 강화 튜토리얼, 마지막 무기 확인, 아트 스타일(B) 확정, 무기 15종 아트 | 완료 (확률표 2026-11-18 확정) |
| M2 전투 | 밤 화면, WASD 이동, 회피, 3계열 자동 공격, 적 2종(스켈레톤·폭발 슬라임), 피해 숫자, XP·레벨업, 180초 생존, 결과 화면 | 완료 |
| M3 루프 | 낮↔밤 연결, 사망·목숨·재도전 스냅샷, 게임 오버와 전체 초기화, 기본 망치 | 완료 (밤 도중 종료 = 패배, 포기 = 패배) |
| M4 경제 | 무기 판매, 상인 Morr(DAY 3): 생명의 심장, 강화 보호석, 부활석 | 완료 (+ 행운·장인 강화석, 시간 역행석. 스킬 초기화 서적은 M5) |
| M5 성장 | 레벨업, 스킬트리 약 40노드(400개로 확장 가능한 구조), 드래그·확대 UI | 완료 (원소 5종 핵심 효과·검색·필터·초기화 서적 포함) |
| M6 보스 | DAY 5 Kordon, 토템 3택1, 토템 장착 | |
| M7 다듬기 | 5속성 효과, 적 1종 추가, 사운드, Higgsfield 아트 교체, 나머지 튜토리얼, 흔들림·섬광 끄기 | |
