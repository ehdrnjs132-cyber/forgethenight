## 4. 새 데이터 구조 (모두 임시값, `src/config/`)

| 파일 | 내용 |
|---|---|
| `doppelganger.ts` | 성향 3종(목표 단계 분포, 최대 시도, 파괴 후 재도전 횟수, 출전 조건), 날짜별 인원·시도 예산·성향 가중치, 이름·칭호 조각, 단서(발광·입자·공명음) 규칙, 공개 조건 |
| `hackslash.ts` | 무기 3종의 콤보 단계별 피해 배율·사거리·각도·경직, 강공격 충전·충격파, 대시 거리·무적, 히트스톱, 도플갱어 피해·HP 공식 |
| `story.ts` | 5막 구간, 날짜 이벤트, 보스 일정(THE FIRST = DAY 50) |
| `cinematics.ts` | 컷신 목록, 파일 경로, 한국어 자막(시간 코드) |

도플갱어 생성 규칙 (확정 전 임시값):
1. 날짜마다 시도 예산 `B`가 정해진다. 각 도플갱어는 +0 무기에서 시작해 플레이어와 **같은 `ENHANCE_TABLE`**로 굴린다.
2. 성향별 목표 단계에 닿으면 멈춘다 (안정형 낮음, 도전형 중간, 올인형은 예산을 다 쓸 때까지).
3. 파괴되면 새 +0 무기로 다시 시작한다 (최대 재도전 횟수까지). 남은 예산이 없으면 가장 마지막 무기로 출전한다. 파괴된 무기는 들고 오지 않는다.
4. 출전 무기의 실제 시도 기록(시도·대성공·성공·유지·하락, 마지막 단계 변화, 잃은 무기 수)을 그대로 저장해 처치 화면에 보여 준다.
5. 라인업은 밤 시작 때 저장된 RNG로 만든다. 같은 날 재도전하면 같은 상대가 나온다.

## 6. 확인 필요 (기본값으로 진행 중)

1. **강화 비용**: 1시간 전 "강화할 때 골드가 좀 들어가야" 결정과 지시서의 "재료나 골드 없이"가 충돌. → 지시서를 따라 **기본 무료**, `ENHANCE_COST_RATE` 하나로 다시 켤 수 있음.
2. **밤의 길이**: 지시서는 "생존"만 언급. → **도플갱어 전원 처치 = 새벽**, 시간 제한 없음.
3. **무기걸이 8칸·열쇠**: 지시서에 언급 없음 → 유지.
4. **숨겨진 엔딩 C 조건**: 지시서대로 미정.
